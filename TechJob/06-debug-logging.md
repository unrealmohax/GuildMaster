# GM-06. Лог и прогон без интерфейса

| Задача | Ветка | Метки коммитов |
|---|---|---|
| **GM-06** | `GM-06_debug_logging` | `[GM-06]` — код, `[TechSpec-06]` — правки этого ТЗ |

Дизайн: [prototype.md → Этапы](../docs/prototype.md#этапы) (этап 1 — «ядро симуляции без интерфейса, проверка по логу»).

## Цель

Проверять симуляцию без интерфейса: прогонять месяцы за секунды, читать подробный лог, повторять ситуации по зерну, собирать цифры для баланса.

## Опирается на

- GM-01: `Simulation`, такт, `SimEvent`, команды, генератор с зерном, заготовка `HeadlessRun` и окна **Run Headless…**.
- GM-03–05: время, люди, состояние и здоровье — то, что сейчас есть в мире.

## Лог симуляции

- Класс `SimLogger` в `GuildMaster.Core`, пишет в файл и (по флагу) в консоль Unity.
- Каждая строка: `[Год.Месяц.День ЧЧ:00] [Система] [Уровень] текст`.
- **Уровни**: `Error`, `Info` (важное: события, решения, деньги), `Debug` (все броски: шанс, выпавшее число, итог), `Trace` (промежуточные расчёты).
- Логгер доступен всем системам через `SimContext`; выключенный уровень не строит строку (прогон на `Info` не должен тормозить из-за `Trace`).
- Файл: `Logs/sim_{зерно}_{дата}.log` в папке проекта (вне Assets).

### Что пишется сейчас

| Уровень | Что |
|---|---|
| `Info` | Все `SimEvent` систем GM-03–05: начало месяца, кандидат пришёл / ушёл / принят, раскрытие черты, смена архетипа, срыв, запой, уход, рана и выздоровление, пустой кошелёк |
| `Debug` | Броски: срыв, уход, осложнение раны, приход кандидата, генерация человека (тип, уровень) |
| `Trace` | Показатели каждого человека раз в сутки: усталость, стресс, довольство и его цель, лояльность, кошелёк |

- **Скрытое тоже в лог**: значения осей характера, скрытые черты (при генерации человека — `Debug`).

## Прогон без интерфейса

Editor-окно **GuildMaster → Run Headless…**

| Поле | По умолчанию |
|---|---|
| Зерно | случайное (показывается) |
| Дней | 360 |
| Уровень лога | Info |
| Бот игрока | «Простой» |
| Число прогонов | 1 (для статистики — до 100 с разными зёрнами) |

### Бот игрока

Бот отдаёт те же команды, что и игрок, через очередь команд (GM-01). Правила бота — отдельные классы, их список расширяемый.

- **Пассивный**: ничего не делает (проверка «мир живёт сам»).
- **Простой** ❔: принимает всех кандидатов в авантюристы.
- **Сценарий**: список команд «в такт N сделать X» из текстового файла — для повторения конкретной игры.

### Сводка прогона

После прогона — файл `Logs/summary_{зерно}.csv` и таблица в окне. Столбцы сводки — расширяемый список: каждый столбец — имя и функция от мира (за месяц или на конец прогона).

- **По месяцам**: людей в гильдии, пришло / ушло, срывов, ран, раскрытых черт, средние усталость / стресс / довольство / лояльность, средний кошелёк, у скольких кошелёк пуст.
- **По людям**: архетип, ранг, ран, в гильдии ли на конец, какие черты раскрылись и когда.
- При нескольких прогонах — средние и разброс.

## Критерии приёмки

- [ ] Прогон 360 дней без UI меньше чем за минуту, с логом и сводкой.
- [ ] Одно зерно + тот же бот → одинаковый лог.
- [ ] Сценарий команд воспроизводит игру.
- [ ] По логу можно восстановить, почему у человека случился срыв или уход (показатели, броски).
- [ ] Прогон на уровне `Info` заметно быстрее, чем на `Trace`.

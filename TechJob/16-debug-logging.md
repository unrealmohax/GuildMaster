# ТЗ 16. Отладка и лог

Дизайн: [prototype.md → Этапы](../docs/prototype.md#этапы) (этап 1 — «ядро симуляции без интерфейса, проверка по логу»).

## Цель

Проверять симуляцию без интерфейса: прогонять месяцы за секунды, читать подробный лог, повторять ситуации по зерну, собирать цифры для баланса.

## Лог симуляции

- Класс `SimLogger` в `GuildMaster.Core`, пишет в файл и (по флагу) в консоль Unity.
- Каждая строка: `[Год.Месяц.День ЧЧ:00] [Система] [Уровень] текст`.
- **Уровни**: `Error`, `Info` (важное: решения с причинами, исходы, деньги), `Debug` (все броски: шанс, выпавшее число, итог), `Trace` (оценки мотивов по каждому варианту).
- В лог попадают **все строки лент** (ТЗ 14) и **скрытое**: профили заказов, перекрытие, воспринимаемое перекрытие, значения осей, скрытые черты.
- Файл: `Logs/sim_{зерно}_{дата}.log` в папке проекта (вне Assets).

## Прогон без интерфейса

Editor-окно **GuildMaster → Run Headless…**

| Поле | По умолчанию |
|---|---|
| Зерно | случайное (показывается) |
| Дней | 360 |
| Уровень лога | Info |
| Бот игрока | «Простой» |
| Число прогонов | 1 (для статистики — до 100 с разными зёрнами) |

### Бот игрока

- **Пассивный**: ничего не делает (проверка «мир живёт сам»).
- **Простой** ❔: Регистратор берёт всё до ранга гильдии; комиссия 20%; важные заказы принимает, если в гильдии есть человек этого ранга; строит Общежитие → Лазарет → Двор, когда денег ≥ цена + 3 месяца расходов; нанимает Лекаря по просимой зарплате; кандидатов в авантюристы принимает всех; в дилеммах выбирает случайно.
- **Сценарий**: список команд «в такт N сделать X» из текстового файла — для повторения конкретной игры.

### Сводка прогона

После прогона — файл `Logs/summary_{зерно}.csv` и таблица в окне:

- по месяцам: казна, доходы и расходы по категориям, репутация, людей, заказов пришло / взято / снято, заданий по уровням результата, гибелей, бегств, срывов, раскрытых черт, средние стресс / довольство / лояльность;
- по людям: архетип, ранг, заданий, ран, жив ли, какие черты раскрылись и когда;
- при нескольких прогонах — средние и разброс.

## Отладочная панель в игре

Только в отладочной сборке, клавиша **F1**.

| Функция | Что делает |
|---|---|
| Зерно | Показать текущее, перезапустить с заданным |
| Скорость ×50 | Отладочная скорость |
| Перемотать | На N часов / дней вперёд |
| Раскрыть всё | Показывать скрытые черты, профиль и шанс заданий (для отладки) |
| Деньги | + / − N |
| Репутация | Задать |
| Человек | Создать с заданной ролью и чертами; изменить параметр, ось, показатель |
| Заказ | Создать с заданным типом и рангом |
| Дилемма | Вызвать любую дилемму для выбранного человека |
| Событие | Вызвать засаду, находку, срыв |

## Критерии приёмки

- [ ] Прогон 360 дней без UI меньше чем за минуту, с логом и сводкой.
- [ ] Одно зерно + тот же бот → одинаковый лог.
- [ ] Сценарий команд воспроизводит игру.
- [ ] Отладочная панель доступна только в отладочной сборке.
- [ ] По логу можно восстановить, почему человек поступил так (мотивы, причины, броски).

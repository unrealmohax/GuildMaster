# Черта → влияние

Как черты работают внутри механизмов: [модель решений](decision-model.md) (мотивы, оценка риска), [состояние](state.md), [расчёт задания](quests.md) (моменты напряжения).

## ✅ Решено

- **Формат**: сейчас сила влияния — стрелками (↑↑ сильно, ↑ заметно, ↓ ослабляет), **числа — при сборке**.
- **Приобретённые черты не видны сразу** — раскрываются, когда проявятся, как и остальные.
- **Особые черты в прототипе — все 12** из таблицы ниже.
- **Черты не привязаны к архетипам**: любая позиция на любой оси возможна у любого архетипа (бывает и трусливый Щит, и безрассудный Лекарь).

## ✅ Базовые оси

Утверждено для прототипа, доработаем по итогам тестов. Ось — шкала, влияние растёт к полюсу. Ниже — крайние полюса.

### Риск: Трус ↔ Безрассудный

| | Трус | Безрассудный |
|---|---|---|
| Мотивы | Безопасность ↑↑, Слава ↓ | Слава ↑, Безопасность ↓↓ |
| Состояние | Стресс набирает быстро | Стресс набирает медленно |
| Оценка риска | Переоценивает | Недооценивает |
| Момент напряжения | Паника или бегство; голосует за отступление | Бросается вперёд, чаще ранен; против отступления |
| Раскрывается | Первая паника или бегство | Первый бросок вперёд без приказа |

### Деньги: Бескорыстный ↔ Жадный

| | Бескорыстный | Жадный |
|---|---|---|
| Мотивы | Деньги ↓, берёт невыгодные важные задания | Деньги ↑↑ |
| Состояние | Довольство мало зависит от оплаты | Довольство сильно падает от высокой комиссии и пустого кошелька |
| Группы | Всё равно, сколько человек | Предпочитает маленькие группы |
| Прочее | — | Легче переманить |
| Раскрывается | Берёт задание почти без оплаты | Отказ из-за оплаты, спор при дележе |

### Люди: Одиночка ↔ Командный

| | Одиночка | Командный |
|---|---|---|
| Мотивы | Товарищи ↓, соло-задания | Товарищи ↑↑, ищет группу |
| Состояние | В группе — стресс ↑, довольство ↓ | В одиночку — стресс ↑; друзья быстро снимают стресс |
| Отношения | Дружбы медленно | Дружбы быстро |
| Раскрывается | Первый отказ идти группой | Первый отказ идти одному |

### Труд: Ленивый ↔ Амбициозный

| | Ленивый | Амбициозный |
|---|---|---|
| Мотивы | Отдых ↑↑, тренировки ↓, лёгкие задания | Слава ↑↑, тренировки ↑, сложные задания |
| Состояние | — | Провал задания на повышение — сильный стресс |
| Раскрывается | Долго не выходит на задания и тренировки | Сам просится на сложное или на повышение |

### Верность: Наёмник ↔ Преданный

| | Наёмник | Преданный |
|---|---|---|
| Состояние | Лояльность растёт медленно, падает быстро | Лояльность растёт быстро, падает медленно |
| Решения | Раз в месяц всерьёз взвешивает уход | Держится даже при плохих условиях |
| Раскрывается | Первый торг: «мне предлагают больше» | Остаётся, когда все уходят |

### Принципы: Беспринципный ↔ Честный

| | Беспринципный | Честный |
|---|---|---|
| Решения | Утаивает добычу, берёт «грязные» заказы | Сдаёт всю добычу, отказывается от «грязных» |
| Состояние | Жёсткие законы почти не беспокоят | Несправедливые законы снижают довольство, чаще жалуется |
| Раскрывается | Пойман на утаивании | Отказ от сомнительного заказа, жалоба |

## ✅ Особые черты прототипа (12)

| Черта | Влияние | Раскрывается |
|---|---|---|
| **Ветеран войны** | Хладнокровие в моменты напряжения, но иногда срыв: запой, кошмары | Первый бой или первый срыв |
| **Бывший дезертир** | Под сильным давлением может снова сбежать, даже если храбр по оси | Бегство при сильном давлении |
| **Пьяница** | Утешение ↑↑, но только таверна; тратит деньги, иногда пропускает задание | Пропущенное задание |
| **Хвастун** | Сильно недооценивает риск, поднимает репутацию гильдии | Берётся за непосильное |
| **Железные нервы** | Почти не паникует, стресс от гибели товарищей слабее | Спокоен, когда другие паникуют |
| **Семейный** | Безопасность ↑, отсылает деньги домой, раньше уходит на покой | Отказ от смертельно опасного, обращение с просьбой |
| **Соперник** | Растёт быстрее рядом с соперником, в одной группе — штраф к шансу | Ссора, соревнование |
| **Влюблённый** | Сильнее рядом с любимым (синергия), ломается при его гибели | Просьба ставить их в одну группу |
| **Кошмары** *(приобретённая)* | Хуже спит, быстрее устаёт, может отказываться от похожих заданий | Отказ от похожего задания, плохой сон |
| **Калека** *(приобретённая)* | Одна характеристика сильно снижена | Сразу после ранения — физическая травма |
| **Потерявший товарища** *(приобретённая)* | Временный спад, затем сломается или ожесточится | Спад после гибели напарника |
| **Проверенный** *(приобретённая)* | Лояльность и слаженность выше | Остаётся с гильдией в трудный момент (другие уходят к конкуренту, гильдия на грани банкротства) |

Утверждено для прототипа, доработаем по итогам тестов.

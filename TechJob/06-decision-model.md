## Цель

Каждый человек сам выбирает, что делать, по мотивам, которые задают черты и состояние. Игрок влияет только через ценность вариантов.

## Точки решения

| Когда | Что решается |
|---|---|
| **Утро** (06:00–09:00, раз на человека) | Что делать сегодня |
| **Освободился** (вернулся с задания, закончил отдых, вылечился) | Что делать дальше (если не ночь) |
| **Вечер** (18:00) | Таверна или отдых |
| **Ночь** (22:00) | Сон (без выбора) |
| **По событию** | Приглашение в группу (ТЗ 07), решение после провала раунда (ТЗ 09), находка (ТЗ 09) |
| **Раз в месяц** | Остаться или уйти (ТЗ 05) |

Люди на задании, в срыве, в Лазарете с тяжёлой раной — решений не принимают.

## Действия

| Действие | Когда доступно |
|---|---|
| `TakeOrder(orderId)` — взять заказ с доски (один или с группой) | Утро, днём до 14:00 |
| `Train` | Есть Тренировочный двор и свободное место |
| `Rest` | Всегда |
| `Heal` (Лазарет) | Есть рана |
| `Tavern` | Вечер (днём — ❔ только Пьяница или стресс > 60) |
| `SeekParty` — искать группу под заказ | Вместе с `TakeOrder` (ТЗ 07) |
| `FileRequest` — подать обращение | Через триггеры дилемм (ТЗ 13), не как обычный выбор |
| `Leave` — уйти из гильдии | Только ежемесячная проверка (ТЗ 05) |

## Шаг 1. Запреты

Отбросить недоступное:
- заказы выше ранга гильдии человека;
- заказы, запрещённые распоряжениями (например, «от ранга C — только группой» — соло нельзя);
- задания при тяжёлой ране, усталости > 90, срыве;
- тренировку без двора или без мест;
- заказы, уже взятые другими.

## Шаг 2. Мотивы и веса

Шесть мотивов: **Деньги, Слава, Безопасность, Товарищи, Отдых, Утешение**.

**Вес мотива** = 1 × множители черт × множители состояния.

- **Черты** (ТЗ 04): каждая ось и особая черта дают множители по стрелкам (↑↑ × 2 … ↓↓ × 0,25; для осей — плавно от центра).
- **Состояние** ❔:

| Условие | Множитель |
|---|---|
| Кошелёк меньше расходов на неделю | Деньги × 2 |
| Усталость > 50 | Отдых × (1 + (усталость − 50) / 25) |
| Стресс > 40 | Утешение × (1 + (стресс − 40) / 30), Безопасность × 1,3 |
| Лёгкая рана | Безопасность × 1,3 |

## Шаг 3. Ценность вариантов

Каждый вариант получает оценку **0..1 по каждому мотиву**. ❔ Формулы (все коэффициенты — в `BalanceSettings.Decisions`):

### Заказ

- Сначала человек **оценивает шанс** — **воспринимаемое перекрытие** (ТЗ 09): профиль «кто пойдёт» (он сам или предполагаемая группа) против профиля задания, **искажённого**:
  - неточностью описания (±10%, одна и та же для всех, кто смотрит на этот заказ);
  - ошибкой оценки риска по чертам: трус — требования × 1,3; безрассудный × 0,7; Хвастун × 0,6.
- `шанс` = воспринимаемое перекрытие (0..1).

| Мотив | Оценка |
|---|---|
| Деньги | `min(1, ожидаемая доля награды / (расходы за 7 дней))` × шанс |
| Слава | `ранг заказа / ранг человека` (G = 1 … C = 5), не больше 1; + 0,2 если это задание на повышение |
| Безопасность | `шанс` ² (низкий шанс резко пугает) |
| Товарищи | 0 соло; 0,5 в группе; +0,3 если в группе друг; +0,2 если группа постоянная |
| Отдых | `1 − усталость/100` − 0,5 (отрицательно, если устал) |
| Утешение | 0 |

`ожидаемая доля` = награда × (1 − комиссия) + доплата, делённая на размер группы (или по рангу характеристик — ТЗ 09).

### Прочие действия

| Действие | Деньги | Слава | Безопасность | Товарищи | Отдых | Утешение |
|---|---|---|---|---|---|---|
| Тренировка | 0 | 0,4 (Амбициозному — это путь к рангу) | 1 | 0,2 (если тренируются другие) | −0,3 | 0 |
| Отдых | 0 | 0 | 1 | 0 | усталость/100 | 0,3 |
| Лечение | 0 | 0 | 1 | 0 | 0,8 | 0,3 |
| Таверна | −(цена/кошелёк) | 0 | 1 | 0,6 + 0,1 за каждого друга там | 0,3 | стресс/100 + 0,2 |

**Ценность варианта** = Σ (вес мотива × оценка по мотиву).

## Шаг 4. Выбор

- Отсортировать по ценности. С вероятностью `bestChoiceChance` (80%) — лучший, иначе — второй.
- ❔ Если ценность лучшего заказа ниже ценности отдыха — человек не берёт заказ сегодня.

## Шаг 5. Причины

- Для каждого решения записать **2–3 главные причины** — мотивы с наибольшим вкладом (вес × оценка) и факторы состояния.
- **Показывать игроку** причины только для **важных** решений: отказ от заказа, который ему предлагали (группа, дилемма), отказ идти соло / в группе, уход из гильдии, бегство (ТЗ 09), отказ от задания из-за Кошмаров.
- **Скрытые черты не называть.** Причина строится из мотива и состояния:

| Главная причина | Текст (черта скрыта) | Текст (черта раскрыта) |
|---|---|---|
| Безопасность (трус) | «слишком опасно, по его мнению» | «трус — не пойдёт на такое» |
| Деньги | «мало платят для его ранга» | «жадный — мало платят» |
| Товарищи (одиночка) | «не хочет идти с группой» | «одиночка» |
| Отдых | «устал» | «устал» |
| Утешение | «тяжело после …» | «тяжело после …» |

- ❔ Какие решения считаются важными — в дизайне открытый вопрос; список выше — по умолчанию.

## Критерии приёмки

- [ ] Каждый свободный человек утром выбирает занятие; решения видны в логе с причинами.
- [ ] Запреты работают (ранг, распоряжения, здоровье, усталость).
- [ ] Черты сдвигают выбор: в прогоне на год трусы берут заметно более лёгкие заказы, жадные — более дорогие, одиночки чаще ходят соло.
- [ ] Пустой кошелёк повышает готовность рисковать.
- [ ] Комиссия и доплата меняют, кто и что берёт.
- [ ] Причины важных решений видны игроку и не выдают скрытые черты.

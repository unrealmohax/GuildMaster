# Модель решений авантюриста

Человек каждый раз выбирает **лучший для себя вариант**, а черты и состояние определяют, что для него «лучше».

Связанные системы: [traits.md](traits.md), [state.md](state.md), [quests.md](quests.md), [laws.md](laws.md).

## ✅ Решено

### Когда принимаются решения

- **Утро** — что делать сегодня.
- **Когда освободился** — вернулся с задания, отдохнул.
- **По событию** — предложение соперника, гибель друга, срочный заказ.
- **Раз в месяц — крупные решения**: остаться или уйти (на покой, к конкуренту, в другой город).

### Действия

- Взять задание (конкретное, с доски);
- отдыхать / спать;
- лечиться;
- тренироваться (где именно);
- таверна — развлечься, пообщаться;
- искать группу / вступить в неё;
- подать обращение игроку (просьба, жалоба);
- уйти из гильдии.

### Сначала запреты

Прежде чем выбирать, человек отбрасывает невозможное:
- задания выше его ранга гильдии;
- то, что запрещают законы;
- то, что не позволяет здоровье;
- для спецгруппы — обычные задания.

### Мотивы

У каждого варианта есть ценность по мотивам:

| Мотив | Что важно |
|---|---|
| **Деньги** | Заработать |
| **Слава** | Ранг, признание, подвиги |
| **Безопасность** | Не рисковать жизнью |
| **Товарищи** | Быть с другими, с друзьями |
| **Отдых** | Восстановить силы |
| **Утешение** | Снять стресс |

- **Черты** задают вес мотивов: Жадному важнее деньги, трусу — безопасность, амбициозному — слава, командному — товарищи, ленивому — отдых.
- **Состояние** усиливает мотивы: устал — отдых; кошелёк пуст — деньги; стресс — утешение и безопасность.
- Человек выбирает вариант с лучшей суммой.

### Случайность

Обычно выбирается лучший вариант, иногда — второй по ценности. Люди предсказуемы, но не роботы.

### Ошибки в оценке риска

Человек оценивает опасность **со своей точки зрения**:
- безрассудный и Хвастун **недооценивают** риск;
- трус **переоценивает** риск.

### Где здесь игрок

Игрок меняет **ценность вариантов**, а не приказывает:
- **комиссия и доплата** — ценность денег у задания;
- **законы** — запреты и ценности;
- **постройки** — ценность отдыха и утешения (таверна, баня, храм);
- **рекомендация координатора** — ценность предложенной группы (зависит от доверия к координатору);
- **обещания и дилеммы** — через довольство и лояльность.

### Причины видны игроку — частично

Решение запоминает главные причины, игрок видит их **частично**:
- причины показываются только для **важных** решений: отказ, бегство, уход (для обычных — «утром пошёл в таверну» — нет);
- **скрытые черты не выдаются**: игрок видит «испугался» или «кажется, боится риска», а не «трус». Уже раскрытые черты называются прямо.

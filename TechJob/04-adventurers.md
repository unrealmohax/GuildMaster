# ТЗ 04. Авантюристы

Дизайн: [adventurers.md](../docs/mechanics/adventurers.md), [archetypes.md](../docs/mechanics/archetypes.md), [traits.md](../docs/mechanics/traits.md), [trait-effects.md](../docs/mechanics/trait-effects.md), [lifecycle.md](../docs/mechanics/lifecycle.md). Числа: [numbers.md → Авантюристы](../docs/content/numbers.md#авантюристы).

## Цель

Модель авантюриста: параметры, ранги, архетип, черты (скрытые), отношения, генерация, рост, приход и уход.

## Модель данных `Adventurer`

| Поле | Тип | Что это |
|---|---|---|
| `Id`, `Name`, `Gender` | int, string, `Male`/`Female` | ❔ Пол 50/50 |
| `Age` | int | Только для отображения, старения в прототипе нет. ❔ 17–35 при генерации |
| `Stats` | float[14] | Параметры по `StatId`, 1..99 (выше 99 — только ростом) |
| `Axes` | float[6] | Оси характера −100..+100 |
| `RevealedAxes` | bool[6] | Раскрыта ли ось |
| `Traits` | список `TraitInstance` | Особые черты: `traitId`, `revealed`, `partnerId` (для Соперника, Влюблённого), `acquiredAtHours`, данные черты (например, какая характеристика снижена у Калеки) |
| `GuildRank` | G, F, E, D, C | Ранг гильдии |
| `RankPoints` | int | Очки ранга |
| `PromotionReadyAtHours` | long | Когда доступно задание на повышение (после провала — через 30 дней) |
| `Archetype`, `PowerScore` | id, float | Вычисляются (см. ниже) |
| `State` | см. ТЗ 05 | Здоровье, усталость, стресс, довольство, лояльность, кошелёк |
| `Housing` | `City` / `Dorm` | Где живёт |
| `Activity` | enum | Чем занят сейчас (ТЗ 06) |
| `PartyId`, `PermanentPartyId` | int | Текущая и постоянная группа |
| `Memory` | флаги | Для цепочек: «сбегал», «прощён после бегства», «брал в долг» и т.п. |
| `JoinedAtHours`, счётчики | | Дата вступления, выполнено / провалено заданий |

## Параметры

- 14 параметров: 8 характеристик и 6 навыков (словарь — [README](README.md#словарь-кодовых-имён)).
- Все видны игроку точно.
- **Эффективное значение** параметра = базовое × модификаторы (Калека −30%, лёгкая рана, усталость — ТЗ 05). В расчётах заданий используется эффективное.
- **Естественный минимум — 10**: базовое значение никогда не ниже 10. ❔ Калека тоже не опускает характеристику ниже 10; временные множители (рана, усталость, паника) — могут.

### Рост

| Как растёт | Правило |
|---|---|
| Тренировка, навык | + `trainSkillPerDay` × (1 − значение/100) за день тренировки (8 часов на дворе = 1 день; меньше — пропорционально) |
| Тренировка, характеристика | то же, делённое на `characteristicSlowdown` (3) |
| Выше 99 | × `above99Multiplier` (0,1) |
| Опыт на задании | по каждой оси, где у задания требование > 0: +0,5 (успех) / +0,3 (провал). ❔ Для характеристик — тоже делится на 3 и умножается на (1 − значение/100) |
| Хладнокровие | только на заданиях: + `composurePerHardQuest` за задание, где был провал раунда. На дворе не тренируется |
| Слаженность | + 0,5 за групповое задание, + 1 если группа постоянная. На дворе не тренируется |

- ❔ **Что тренируется на дворе**: авантюрист тренирует **основные параметры своего текущего архетипа** (случайно один из двух); Новичок и Мастер на все руки — случайный из двух своих самых высоких. Хладнокровие и Слаженность не тренируются.

## Архетип и ранг характеристик

Пересчитывать раз в сутки и после изменения параметров.

1. Для каждого архетипа вида `Role` (в прототипе — Щит, Боец, Стрелок, Разведчик, Лекарь):
   `оценка = 0,7 × среднее(основные) + 0,2 × среднее(вспомогательные) + 0,1 × среднее(остальные из 14)`.
2. `лучшая` — максимальная оценка.
3. Если `лучшая < noviceThreshold` (25) → **Новичок**, `PowerScore = лучшая`.
4. Иначе, если `лучшая − среднее(все 14) < jackThreshold` (10) → **Мастер на все руки**, `PowerScore = среднее(все 14)`.
5. Иначе → архетип с лучшей оценкой, `PowerScore = лучшая`.

- Смена архетипа — строка в ленте гильдии («Ида теперь — Разведчица»), без автопаузы.
- В карточке — профиль по всем ролям: «Щит 68, Боец 49, …».

## Ранг гильдии

- Ранги прототипа: **G, F, E, D, C**.
- Очки за задания — ТЗ 09. Порог повышения — `Ranks.pointsToNext` (10 / 25 / 50 / 90).
- Когда очков хватает и `PromotionReadyAtHours` прошёл — появляется **задание на повышение** (ТЗ 09).
- ❔ После повышения очки обнуляются.
- Авантюрист может брать заказы **своего ранга и ниже**.

## Оси характера

- Хранятся как число −100..+100. Смысл полюсов — [README](README.md#оси-характера-axisid).
- **Сила влияния по оси** (для эффектов со стрелкой, ТЗ 02): если эффект принадлежит полюсу, у которого знак совпадает со значением оси,
  `t = |значение| / 100`, `множитель = 1 + t × (множительСтрелки − 1)`.
  Пример: трус −50, «Безопасность ↑↑» (× 2) → × 1,5.
- ❔ **Крайний полюс** — |значение| ≥ 70 (для правил «только у крайнего», например бегство труса).
- ❔ **Нейтральная ось** — |значение| < 30: эффекты полюсов почти не заметны, раскрывать нечего.

### Раскрытие осей

- Ось раскрывается, когда её полюс **впервые реально повлиял на исход**. Код вызывает `RevealService.TryRevealAxis(adventurer, axis, context)` в местах ниже.
- Раскрывать только если |значение| ≥ 30. После раскрытия в карточке — название полюса («Трус»), при |значение| < 70 — со словом «склонен» («склонен к риску»).
- ❔ Нейтральная ось раскрывается сама через 60 дней в гильдии как «уравновешен».
- Раскрытие — **важное** событие: строка из [event-feed.md → Раскрытие черт](../docs/content/event-feed.md#раскрытие-черт), автопауза.

| Полюс | Когда раскрывается |
|---|---|
| Трус | Паника или бегство в момент напряжения |
| Безрассудный | Бросок вперёд |
| Бескорыстный | ❔ Взял заказ, где его доля награды ниже половины среднего для ранга |
| Жадный | Отказался от заказа, главная причина — деньги (ТЗ 06); спор в дилемме «Ссора из-за добычи» |
| Одиночка | Отказался от группы и пошёл один, хотя группа звала |
| Командный | Отказался идти в одиночку |
| Ленивый | ❔ 7 дней подряд без заданий и тренировок при хорошем здоровье и низкой усталости |
| Амбициозный | ❔ Сам взял заказ высшего доступного ранга или задание на повышение в первый же день |
| Наёмник | ❔ Ежемесячная проверка ухода, в которой главная причина — деньги |
| Преданный | ❔ Остался, когда гильдия в банкротстве или кто-то ушёл в этом месяце, при лояльности ниже 40 |
| Беспринципный | ❔ Пойман на утаивании добычи (шанс 30% при каждом утаивании) |
| Честный | ❔ Выбор в дилемме «Ссора из-за добычи» или 60 дней без утаивания при крайнем полюсе |

## Особые черты

12 черт прототипа — [trait-effects.md](../docs/mechanics/trait-effects.md#-особые-черты-прототипа-12).

### Правила

- У человека **0–4** особые черты, **не больше одной из категории**, без несовместимых (Железные нервы ↔ Кошмары; Сирота гильдии ↔ Беглый преступник — вне прототипа).
- **Новая приобретённая черта заменяет старую приобретённую.**
- **Все черты скрыты**, включая приобретённые; раскрываются по триггеру из таблицы.

### Эффекты и триггеры

Числа — `BalanceSettings`; где число не утверждено — ❔.

| Черта | Эффект в коде | Как появляется | Раскрытие |
|---|---|---|---|
| Ветеран войны | Паника −0,2. ❔ После задания с провалом раунда — шанс 5% срыва (запой: 2 дня в таверне, стресс −) | При генерации | Первый момент напряжения или первый срыв |
| Бывший дезертир | Бегство +0,1 при стрессе > 60, даже если не трус | При генерации | Бегство |
| Пьяница | Мотив «Утешение» ↑↑, но утешение — только в таверне. ❔ Каждое утро шанс 10% (20% при стрессе > 50) пропустить день в таверне | При генерации | Пропущенный день / задание |
| Хвастун | Ошибка оценки риска −0,4. ❔ +1 к репутации гильдии за каждый успех | При генерации | Взял заказ с воспринимаемым перекрытием ≥ 60%, а реальным < 40% |
| Железные нервы | Паника −0,3, стресс от гибели товарищей × 0,5 | При генерации | Не запаниковал, когда в группе кто-то запаниковал |
| Семейный | Мотив «Безопасность» ↑. ❔ Отсылает домой 30% дохода. ❔ Ежемесячная проверка ухода: шанс × 1,5 | При генерации | Отказ от заказа с воспринимаемым перекрытием < 50%; дилемма «Просьба в долг» |
| Соперник | Связан с партнёром. ❔ Опыт на совместном задании × 1,2; в одной группе — −10% к перекрытию | При генерации (готовая пара) | ❔ Первое совместное задание или первая ссора |
| Влюблённый | Связан с партнёром. Синергия +10% в одной группе. При гибели партнёра: стресс +60, черта «Потерявший товарища» | При генерации (готовая пара) | Дилемма «Влюблённые просят одну группу» |
| Кошмары *(приобр.)* | Усталость растёт × 1,3; ❔ шанс 50% отказаться от заказа того же типа, после которого появилась | ❔ Шанс 30% после катастрофы или гибели товарища на задании | Отказ от такого заказа |
| Калека *(приобр.)* | Одна характеристика −30% навсегда (та, что связана с раной: ❔ случайная из Силы, Выносливости, Ловкости, Реакции) | Увечье (ТЗ 05) | Сразу после ранения |
| Потерявший товарища *(приобр.)* | ❔ 30 дней: снятие стресса × 0,5. Затем 50/50: «сломался» (стресс +30) или «ожесточился» (Хладнокровие +5) | Гибель друга (отношения ≥ 40) или партнёра Влюблённого | Сразу после спада — строка «После гибели … другой» |
| Проверенный *(приобр.)* | ❔ Лояльность +10, Слаженность +5 при появлении | ❔ В начале месяца, если гильдия в банкротстве или кто-то ушёл за прошлый месяц, а он в гильдии ≥ 180 дней и лояльность ≥ 50 | Сразу при появлении |

## Отношения между людьми

- Хранилище пар: `Relation(a, b)` — ❔ число −100..+100 (симметричное) и счётчик совместных заданий.
- ❔ Метки: ≥ 40 — **друзья**, ≤ −40 — **неприязнь**; 10+ совместных заданий — **давние напарники**.
- ❔ Изменения:

| Что | Изменение |
|---|---|
| Вечер в таверне вместе | +0,5 |
| Совместное успешное задание | +3 |
| Совместное тяжёлое задание (провалы, раны) | +2 |
| Ссора (вечером, шанс 5% при отношениях < −20 или у Соперников) | −10 |
| Бегство одного из группы | −20 у всех брошенных к беглецу |
| Дилеммы (ТЗ 13) | по варианту |

## Генерация авантюриста

1. Пол, имя, возраст.
2. **Целевая роль**: случайно из 5 ролей; ❔ с шансом 20% — «без роли» (выйдет Новичок).
3. Характеристики 10–40, навыки 10–30, Слаженность 20–60. **Естественный минимум всех параметров — 10.**
4. Поднять 1–2 основных параметра целевой роли: характеристики — до 40–60, навыки — до 50.
5. Оси: ❔ нормальное распределение, среднее 0, разброс 45, обрезать до ±100.
6. Особые черты: у стартовых — 0–1, у пришедших позже — 0–2; только черты «от рождения» (8). Черты с партнёром — только если в гильдии есть подходящий партнёр, иначе перебросить.
7. Кошелёк 20–100, ранг G, жильё — Общежитие, если есть свободное место, иначе город.
8. Посчитать архетип и ранг характеристик.

### Старт (6 человек)

- Роли случайные (п. 2 выше).
- 1–2 человека — ранг F (их поднятые параметры +10).
- **Разнообразие**: ❔ перебрасывать оси, пока ни на одной оси нет больше двух человек на одном крайнем полюсе.
- **Особые черты**: всего 2–3 на шестерых.
- **Готовые отношения**: 1–2 пары — ❔ случайно «старые друзья» (+50), «соперники» (черта Соперник обоим) или «влюблённые» (черта Влюблённый обоим).

## Приход новых людей

- Раз в сутки: шанс `3% + репутация × 0,3%` (× 1,5 при распоряжении «Еда и жильё для новичков»). Не больше 30 человек (включая ожидающих кандидатов).
- ❔ Появляется **кандидат**: карточка с именем, архетипом, рангом, параметрами (черты скрыты). Игрок **принимает или отказывает**; без ответа 3 дня — кандидат уходит. Строка в ленте гильдии, без автопаузы.

## Уход

- Ежемесячная проверка ухода — ТЗ 05.
- Гибель — ТЗ 09. Бегство и исчезновение — ТЗ 09. Изгнание — дилемма «Беглец вернулся» (ТЗ 13).
- Ушедший или погибший удаляется из активных, но остаётся в архиве (для отчёта месяца и лент).

## Критерии приёмки

- [ ] Генерация 1000 человек: параметры в диапазонах, у каждого читается архетип, распределение архетипов разумное (Новичков 15–30%).
- [ ] Формула архетипа и ранга характеристик покрыта тестами (пример Щита из [adventurers.md](../docs/mechanics/adventurers.md#ранг-характеристик) даёт ≈ 68).
- [ ] Старт: 6 человек, 2–3 особые черты, 1–2 готовые пары, нет трёх человек на одном крайнем полюсе.
- [ ] Черты скрыты до триггера, раскрытие даёт важную строку и автопаузу.
- [ ] Рост параметров замедляется к 99 и почти останавливается выше.
- [ ] Кандидаты приходят с нужной частотой, без ответа уходят через 3 дня.

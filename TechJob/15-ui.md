# GM-15. Интерфейс

| Задача | Ветка | Метки коммитов |
|---|---|---|
| **GM-15** | `GM-15_ui` | `[GM-15]` — код, `[TechSpec-15]` — правки этого ТЗ |

Дизайн: [prototype.md → Экраны](../docs/prototype.md#экраны), [core-loop.md](../docs/core-loop.md). Технология: **uGUI + TextMeshPro** (ТЗ 01).

## Цель

Восемь экранов без графики — списки, карточки, ленты. Игрок наблюдает за людьми и принимает решения, не меняя мир напрямую (только командами, ТЗ 01).

## Общие требования

- Опорное разрешение **1920×1080**, Canvas Scaler — Scale With Screen Size.
- ❔ Тёмная тема, один акцентный цвет, шрифт с кириллицей (TMP SDF). Иконки — простые символы или текст.
- Навигация — левая панель: **Гильдия, Доска, Задания, Казна, Распоряжения**. Карточка авантюриста и обращения открываются поверх.
- Любое имя человека, заказа, задания в тексте — **кликабельно** (переход).
- UI обновляется по событиям симуляции, не каждый кадр целиком.

## Верхняя панель (всегда видна)

| Элемент | Что показывает / делает |
|---|---|
| Дата и время | «День 12, месяц 1, год 1 · 14:00» + фаза дня (утро / день / вечер / ночь) |
| Скорость | ⏸ ×1 ×2 ×4, текущая подсвечена (горячие клавиши — ТЗ 03) |
| Казна | Сумма; красным при минусе; клик — экран «Казна» |
| Репутация | Число 0–100 |
| Люди | «14 / 30» |
| Уведомления | Колокольчик со счётчиком: важные заказы, кандидаты, обращения, отчёт месяца |
| Банкротство | Если идёт — таймер «до закрытия: 3 мес. 12 дн.» красным |

## Экраны

### 1. Гильдия

Вкладки + **лента гильдии** справа (всегда на этом экране).

- **Люди**: таблица — имя, архетип, ранг, занятие («на задании: охота у …», «тренируется», «в таверне», «лечится»), значки ран, полоски усталости и стресса, довольство, лояльность словами, кошелёк. Фильтры по занятию. Сортировка по столбцам. Клик — карточка.
- **Группы**: постоянные группы и их члены.
- **Постройки**: список с состоянием (готова / строится — сколько дней / в очереди), вместимостью («Общежитие 7/10»). Кнопка «Построить» для непостроенных — с ценой и сроком. Очередь — перетаскиванием или кнопками ↑↓.
- **Персонал**: сотрудники (должность, уровень, зарплата, долг по зарплате), вакансии, кандидаты — «Предложить зарплату…», «Уволить».

### 2. Доска

- **Слева** — заказы на доске: тип, ранг, заказчик, близко/далеко, награда, доплата, сколько висеть, кто взял.
- **Справа** — выбранный заказ: описание с намёками, поле «Доплата» (команда).
- **Ждут решения** — важные заказы и событийные задания: «Принять» (с доплатой) / «Отклонить»; для событийного — выбор ранга G–C.
- **Правила Регистратора**: переключатели по 4 типам, «брать самому до ранга …», «награда не ниже …».
- **Комиссия** — ползунок 0–50%.
- Профиль задания и шанс **не показываются никогда**.

### 3. Карточка авантюриста

| Блок | Содержимое |
|---|---|
| Шапка | Имя, пол, возраст, архетип, ранг гильдии + полоска очков, ранг характеристик |
| Профиль ролей | «Щит 68, Боец 49, Разведчик 30…» |
| Параметры | 8 характеристик и 6 навыков — точные числа |
| Характер | 6 осей: нераскрытая — «?», раскрытая — название полюса («Трус», «склонен к риску», «уравновешен») |
| Особые черты | Только раскрытые. ❔ Число скрытых не показывать |
| Состояние | Усталость, стресс, довольство — полоски с числом; лояльность — словами (ТЗ 05) |
| Здоровье | Раны со сроком («Тяжёлая рана — 9 дн.»), Калека |
| Деньги | Кошелёк, долг гильдии, жильё (город / общежитие) |
| Отношения | Друзья, неприязнь, соперник, влюблённый (раскрытые) |
| Сейчас | Занятие; для важных решений — причина (ТЗ 06) |
| История | Заданий выполнено / провалено; последние строки ленты о нём |

### 4. Задания (задание в пути)

- **Слева** — идущие задания: тип, место, группа, фаза («путь туда», «на месте, раунд 2», «назад»).
- **Справа** — выбранное: заказ, участники (значки ран, паника, «повернул назад», «сбежал», «погиб»), полоска фазы, **проваленные раунды — 5 делений**, **лента задания**.
- Недавно вернувшиеся (30 дней) — отдельным списком с итогом.

### 5. Обращение

- **Список** открытых обращений (из колокольчика): заголовок, от кого, сколько осталось до ответа.
- **Карточка** (поверх): от кого (имя, архетип), заголовок, текст, 2–3 кнопки вариантов, под каждой — видимые последствия, таймер «ответить до …». Выбор — команда `AnswerDilemma`.

### 6. Казна

- Казна сейчас, журнал операций с фильтром по категориям.
- История отчётов месяца (выбор месяца) — разделы из ТЗ 10.
- Состояние банкротства.

### 7. Распоряжения

- 4 карточки: название, описание, плюс, цена, переключатель, выбор области (ранги — кнопки G–C), срок (бессрочно / 7 / 30 дней), «осталось N дней».

### 8. Время

- Управление скоростью — на верхней панели.
- **Календарь** (по клику на дату): текущая дата, до начала месяца N дней, ближайшие события — окончание стройки, сроки ответа на обращения и важные заказы, возвращение групп.
- **Настройки автопаузы** — переключатели по видам событий (ТЗ 03).

## Всплывающие окна

| Окно | Когда | Кнопки |
|---|---|---|
| Автопауза | Сработала автопауза | Строка события, «Перейти», «Продолжить» |
| Кандидат в авантюристы | Пришёл кандидат | Карточка (без черт), «Принять», «Отказать» |
| Кандидат в персонал | Пришёл кандидат | Уровень, просимая зарплата, поле предложения, «Предложить», «Отказать» |
| Отчёт месяца | 1-е число | Отчёт, «Закрыть» |
| Поражение | Банкротство истекло | Итоги, «Начать заново» (новое зерно) |

## По этапам

- **Этап 2**: верхняя панель, «Гильдия» (Люди, Группы, лента), «Доска» (только просмотр), карточка, «Задания», «Время», окно автопаузы.
- **Этап 3**: остальное — правила и комиссия, доплата, важные заказы, постройки, персонал, кандидаты, «Казна», «Распоряжения», обращения, отчёт месяца, поражение.

## Критерии приёмки

- [ ] Все экраны открываются из навигации, данные обновляются на ходу.
- [ ] Ни один экран не показывает профиль задания, шанс или скрытые черты.
- [ ] Все действия игрока — команды; на паузе результат виден сразу.
- [ ] Клики по именам ведут к карточкам и заданиям.
- [ ] Интерфейс читается на 1920×1080 и 1280×720.

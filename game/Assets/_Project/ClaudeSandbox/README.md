# ClaudeSandbox

Песочница Claude: вспомогательные скрипты, генераторы, дампы, замерочные инструменты, черновики.
Версионируется в git. В код проекта что-либо отсюда переезжает **только по прямому указанию** (см. корневой `CLAUDE.md`).

## Содержимое

### `Editor/GameDataGenerator*.cs` — генератор данных прототипа (GM-02)

Меню **GuildMaster → Sandbox → Generate Game Data**. Заводит и заполняет все ассеты в `Assets/_Project/Data/`
по документам (numbers.md, trait-effects.md, archetypes.md, quests.md, event-feed.md, ТЗ 04–14) и собирает `GameConfig`.

- **Перезаписывает целиком** определения, шаблоны ленты, имена и тексты заказов — правки, сделанные руками
  в этих ассетах, пропадут. После ручной правки данных генератор не запускать (или сначала перенести правку в него).
- **`BalanceSettings` не перезаписывает**: числа в ассете остаются как есть; новые разделы, которых в ассете ещё нет,
  получают стартовые значения из кода (поля по умолчанию) и сохраняются на диск.
- Приватные поля ставит отражением: у классов данных нет сеттеров — и не должно быть.
- Части: `GameDataGenerator.cs` — параметры, оси, черты, архетипы, типы заданий (с GM-11 — и «Исследование пещеры»,
  `CaveExploration`: вес генерации 0, тип событийного задания пещеры), события, постройки, персонал, распоряжения; `.Dilemmas.cs` — дилеммы; `.Feed.cs` — шаблоны ленты (с падежами и привязкой `@`, GM-07) и тексты причин ухода `reason.*` (GM-08; строка ухода — с `{причина}`), подписи отчёта месяца `report.*` и названия статей журнала казны `ledger.*`, строка закрытия гильдии `guild.closed` (GM-09), строки доски `guild.board.*` и подписи разделов «Заказы» и «Репутация» (GM-10);
  строки заданий (GM-11, 💡): варианты для одного человека (условие `Solo`), экзамен, раунды пещеры, заказ взят по типам,
  экзамен и ранг, отказ по Кошмарам, бегство, беглец вернулся / исчез, причины `reason.fled` / `reason.nightmares`, раздел
  отчёта «Задания», статьи журнала «Комиссия», «Возврат долгов», «Доплаты», «Событийные задания», «Находки»;
  `.Texts.cs` — имена с шестью падежами (правила склонения и список несклоняемых — там же) и тексты заказов (💡 предложение):
  заказчики, места, враги, грузы — все шесть падежей вручную (GM-10).
- После запуска — **GuildMaster → Validate Data** (или тест `DataValidatorTests.RealConfig_HasNoErrors`).

### `Editor/TimeProbe.cs` — время в Play Mode из меню (GM-03)

Меню **GuildMaster → Sandbox → Time**: `Log State` (время, фаза, такты, пауза, скорость, кадр), `Toggle Pause`,
`Speed 1/2/3`, `Debug Speed`. Нужен для проверки через MCP (`execute_menu_item`), где горячие клавиши не нажать.

- Редактор без фокуса не крутит кадры Play Mode: в настройках проекта `runInBackground` выключен.
  `Toggle Run In Background` включает его на время проверки. **В редакторе это меняет и `PlayerSettings` в памяти** —
  перед выходом из Play Mode выключить тем же пунктом (в лог пишутся оба значения) и проверить, что
  `ProjectSettings.asset` на диске не изменился.

### `Editor/AdventurerProbe.cs` — люди гильдии из меню (GM-04)

Меню **GuildMaster → Sandbox → Adventurers**: `Log Roster` (активные, кандидаты, отношения: параметры, оси с пометкой
раскрытия `!`, черты с партнёром и пометкой «скрыта»), `Accept First Candidate`, `Reject First Candidate` — в Play Mode;
`Preview Start Lineups` — стартовые шестёрки для зёрен 1–3 без Play Mode (симуляция в памяти, сцена не трогается).
Пишет через `Debug.Log` — в MCP читать `read_console` с `types: ["all"]`.

Там же (GM-05) — строка состояния у каждого: занятие, усталость, стресс, довольство, лояльность (числом и словами),
кошелёк, долг, флаги, раны.

### `Editor/StateProbe.cs` — состояние и здоровье из меню (GM-05)

Меню **GuildMaster → Sandbox → State**: `Light Wound First`, `Heavy Wound First`, `Stress +50 First` — первому в гильдии,
командой (как это будет вызывать ТЗ 11), в Play Mode; `Preview 90 Days` — 90 дней для зёрен 1–3 без Play Mode
(симуляция в памяти, кандидаты принимаются): счётчики событий систем состояния и состояние каждого в конце.
Пишет через `Debug.Log` — в MCP читать `read_console` с `types: ["all"]`.

### `Editor/HeadlessProbe.cs` — прогон без интерфейса из меню (GM-06)

Меню **GuildMaster → Sandbox → Headless**: `Year Seed 1 Debug`, `Year Seed 1 Trace` — год с ботом «Простой» в файлы;
`Year Seeds 1-10 Info` — серия из 10 лет (зёрна 1–10) со свёрткой. То же, что кнопка окна **Run Headless…**, но без
окна — для проверки через MCP (`execute_menu_item`). Файлы — в `Logs/` проекта (папка в `.gitignore`), пути и время —
в консоль (`read_console` с `types: ["all"]`). После проверки файлы прогона (`sim_*`, `summary_*`, `scenario_*`) удалить.
Сводка серии с GM-13 — ещё постройки (готовность, Общежитие, Лазарет, двор), персонал и долги по зарплате; бот строит и нанимает.
В меню `execute_menu_item` серии обрывает связь MCP на ~20 с (прогон в главном потоке) — дождаться файлов в `Logs/`.

### `Editor/FeedProbe.cs` — лента событий из меню (GM-07)

Меню **GuildMaster → Sandbox → Feed**: `Dump Templates` — каждый вариант каждого шаблона для мужчины и женщины (Ян / Мара),
названия — метками падежа («место-р») во всех четырёх родах, ошибки подстановки — `!!`; `Year Feed Seed 1` — лента гильдии
за год с ботом «Простой». Для вычитки глазами. Файлы `feed_templates.txt`, `feed_year_1.txt` — в `Logs/` проекта, путь —
в консоль. После проверки удалить.

### `Editor/QuestProbe.cs` — кто какие заказы берёт (GM-11)

Меню **GuildMaster → Sandbox → Quests → Order Preferences 10 Years**: 10 лет симуляции без игрока (зёрна 1–10), на каждое
взятие заказа — полюса осей Риск и Деньги взявшего, реальное перекрытие в одиночку (насколько заказ по силам) и награда
относительно средней по рангу. Итог — в консоль (`read_console` с `types: ["all"]`): трусы должны брать заказы легче смелых,
жадные — дороже бескорыстных. Около 10 секунд, файлов не пишет.

### `Editor/PartyProbe.cs` — группы (GM-12)

Меню **GuildMaster → Sandbox → Parties** (итог — в консоль построчно, `read_console` с `types: ["all"]`, фильтр `PartyProbe`;
файлов не пишет):

- `Groups 10 Years` — 10 лет с ботом «Простой» (зёрна 1–10) и тот же прогон «без групп» (копия данных в памяти, предел группы 1 —
  поведение GM-11): заданий соло / в группе, средний размер, выполнено, гибели, шанс раунда; «дыры» профиля — реальное перекрытие
  собранной группы против случайного набора того же размера из свободных людей нужного ранга; размер групп по тому, кто собрал
  (жадный / командный / одиночка); доля выходов соло по оси Люди; постоянные группы (сложилось, распалось, кто и почему ушёл); отказы
  от приглашений по причинам. Около 40 секунд.
- `Year Time With And Without Parties` — время года (зерно 1, лучший из трёх) с группами и без.
- `Trace Counts Seed 1` — сколько каких строк `Trace` за год (цена оценки групп).
- `Cost Benchmark` — цена отдельных расчётов: перекрытие, веса мотивов, синергии, ценность группы.

### `Editor/PartyChronicle.cs` — летопись постоянных групп (GM-12)

Меню **GuildMaster → Sandbox → Parties → Chronicle Year Seed 1**: год с ботом «Простой» (зерно 1). По каждой постоянной группе —
когда сложилась и из кого, кто вступил и вышел (когда и почему), распад, сколько заданий группой; у каждого — ранг, архетип и ось
Люди на момент события и состав на конец года. Файл `Logs/parties_year_1.txt`, путь — в консоль. После просмотра удалить.

### `Editor/UiSetup.cs` — шрифт и тема интерфейса (GM-14)

Меню **GuildMaster → Sandbox → UI**: `Import TMP Essential Resources` (в `Assets/TextMesh Pro/`: настройки TMP и LiberationSans.ttf),
затем `Build Font And Theme` — статический SDF `Data/UI/LiberationSans Cyrillic SDF.asset` (латиница, кириллица, значки — список символов
в скрипте) и `Data/UI/UiTheme.asset` с этим шрифтом. Шрифт собирается, только если ассета нет: новый значок — удалить ассет и собрать заново.

### `Editor/UiProbe.cs` + `FrameMeter.cs` — снимки экранов и замер кадра (GM-14)

Меню **GuildMaster → Sandbox → UI** (Play Mode): `Capture All 1920x1080` / `1280x720` — Game view в нужном размере и снимки всех экранов
и окон (люди, постройки, персонал, группы, доска, задания, карточка, время, уведомления, отладка), `Capture Current …` — то, что открыто
сейчас (окно автопаузы), `Measure Frames 10s` — длина кадра и время скриптов (такты + интерфейс): среднее, p95, максимум в лог,
`Log Screen State` — экран, окна, время, причины автопаузы. Снимки — `Logs/UiShots/`, после просмотра удалить.
`Restore Game View Size` — вернуть прежний размер Game view и убрать добавленные размеры. Без фокуса окна — Time → Toggle Run In Background
(выключить до выхода из Play Mode). `FrameMeter` — компонент, который зонд добавляет в игре; в сцену не сохраняется.

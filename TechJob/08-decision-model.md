# GM-08. Модель решений авантюриста

| Задача | Ветка | Метки коммитов |
|---|---|---|
| **GM-08** | `GM-08_decision_model` | `[GM-08]` — код, `[TechSpec-08]` — правки этого ТЗ |

Дизайн: [decision-model.md](../docs/mechanics/decision-model.md), [trait-effects.md](../docs/mechanics/trait-effects.md). Числа: [numbers.md → Модель решений](../docs/content/numbers.md#модель-решений).

## Цель

Каждый человек сам выбирает, что делать, по мотивам, которые задают черты и состояние. В этом ТЗ — сам механизм решений и занятия в гильдии без построек: отдых, таверна, сон. Механизм устроен так, что новые действия добавляются как новые варианты со своими оценками.

## Опирается на

- GM-03: фазы дня.
- GM-04: оси и особые черты, отношения.
- GM-05: занятие `Activity`, показатели, кошелёк, раны, срыв, запреты `StateRules`, ежемесячная проверка ухода.
- GM-06: лог. GM-07: лента.

## Точки решения

| Когда | Что решается |
|---|---|
| **Утро** (06:00–09:00, раз на человека) | Что делать сегодня |
| **Освободился** (закончил отдых, вылечился) | Что делать дальше (если не ночь) |
| **Вечер** (18:00) | Таверна или отдых |
| **Ночь** (22:00) | Сон (без выбора) |

- Люди в срыве, с тяжёлой раной, в запое (Пьяница) — решений не принимают, занятие задаёт GM-05.
- Точка решения — расширяемый список: у точки — когда наступает и какие варианты в ней доступны.

## Действия

| Действие | Когда доступно |
|---|---|
| `Rest` | Всегда |
| `Tavern` | Вечер; днём — ❔ только Пьяница или стресс > 60 |
| `Sleep` | Ночь, без выбора |

## Шаг 1. Запреты

Отбросить недоступное (сейчас — только время суток для таверны). Запрет — отдельное правило с причиной; причина пишется в лог (`Debug`).

## Шаг 2. Мотивы и веса

Шесть мотивов: **Деньги, Слава, Безопасность, Товарищи, Отдых, Утешение**.

**Вес мотива** = 1 × множители черт × множители состояния.

- **Черты** (GM-04): каждая ось и особая черта дают множители по стрелкам (↑↑ × 2 … ↓↓ × 0,25; для осей — плавно от центра). Таблица — [trait-effects.md](../docs/mechanics/trait-effects.md).
- **Состояние** ❔:

| Условие | Множитель |
|---|---|
| Кошелёк меньше расходов на неделю | Деньги × 2 |
| Усталость > 50 | Отдых × (1 + (усталость − 50) / 25) |
| Стресс > 40 | Утешение × (1 + (стресс − 40) / 30), Безопасность × 1,3 |
| Лёгкая рана | Безопасность × 1,3 |

## Шаг 3. Ценность вариантов

Каждый вариант получает оценку **0..1 по каждому мотиву**. ❔ Формулы (все коэффициенты — в `BalanceSettings.Decisions`):

| Действие | Деньги | Слава | Безопасность | Товарищи | Отдых | Утешение |
|---|---|---|---|---|---|---|
| Отдых | 0 | 0 | 1 | 0 | усталость/100 | 0,3 |
| Таверна | −(цена/кошелёк) | 0 | 1 | 0,6 + 0,1 за каждого друга там | 0,3 | стресс/100 + 0,2 |

**Ценность варианта** = Σ (вес мотива × оценка по мотиву).

## Шаг 4. Выбор

- Отсортировать по ценности. С вероятностью `bestChoiceChance` (80%) — лучший, иначе — второй.

## Шаг 5. Причины

- Для каждого решения записать **2–3 главные причины** — мотивы с наибольшим вкладом (вес × оценка) и факторы состояния. В лог: решение и причины — `Info`, оценки по каждому варианту и мотиву — `Trace`.
- **Показывать игроку** причины только для **важных** решений. Сейчас важное — уход из гильдии.
- **Скрытые черты не называть.** Причина строится из мотива и состояния:

| Главная причина | Текст (черта скрыта) | Текст (черта раскрыта) |
|---|---|---|
| Безопасность (трус) | «слишком опасно, по его мнению» | «трус — не пойдёт на такое» |
| Деньги | «мало платят для его ранга» | «жадный — мало платят» |
| Товарищи (одиночка) | «не хочет идти с группой» | «одиночка» |
| Отдых | «устал» | «устал» |
| Утешение | «тяжело после …» | «тяжело после …» |

- ❔ Какие решения считаются важными — в дизайне открытый вопрос.

## Доработка готового кода

- **GM-05, расписание-заглушка**: `ActivitySystem` больше не ставит «день — отдых, вечер — таверна» по фазам. Занятие в точках решения ставит `DecisionSystem`. Остаётся за GM-05: сон ночью, срыв, запой Пьяницы, отдых при тяжёлой ране.
- **GM-05, причина ухода**: вместо `LeaveCause.LowLoyalty` без разбора — 2–3 главных мотива человека по весу и состояние (шаг 5): «пустой кошелёк», «тяжело после …», «устал». Уход — важное решение, причина видна игроку.
- GM-06: в сводку — доли занятий по часам (отдых, таверна) за месяц.

## Критерии приёмки

- [ ] Каждый свободный человек в точках решения выбирает занятие; решения видны в логе с причинами.
- [ ] Черты и состояние сдвигают выбор: при высоком стрессе и у командных таверна чаще; Пьяница ходит в таверну днём.
- [ ] Причина ухода строится из мотивов и не выдаёт скрытые черты.
- [ ] Одно зерно → те же решения.

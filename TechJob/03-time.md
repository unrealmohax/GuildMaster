## Цель

Игровое время по часам: такт = 1 игровой час, календарь, ритм дня, скорости, пауза, автопауза.

## Календарь

- `GameTime`: `Hour` (0–23), `Day` (1–30), `Month` (1–12), `Year` (с 1). Плюс `TotalHours` — счётчик с начала игры (для сроков и длительностей).
- ❔ Старт игры: год 1, месяц 1, день 1, **06:00** — утро, доска уже работает.
- Все сроки в симуляции хранятся как «час окончания» в `TotalHours`.
- Времён года в прототипе **нет**.

## Ритм дня

| Фаза | Часы (из `BalanceSettings`) | Что происходит |
|---|---|---|
| **Утро** | 06:00–09:00 | Новые заказы на доске (в 06:00), решения людей: взять задание, тренироваться, отдыхать. Группы выходят |
| **День** | 09:00–18:00 | Задания, тренировки, лечение, отдых |
| **Вечер** | 18:00–22:00 | Таверна, общение (отношения), возвращения |
| **Ночь** | 22:00–06:00 | Сон в гильдии (общежитие) или в городе |

- ❔ **Ночью группы в пути не идут, а ночуют** (с 20:00 до 06:00): этап пути ставится на паузу, в ленту — строка ночлега. Раунды задания ночью тоже не идут. ✅ «Далеко» — 24–36 часов **дневного** пути; при 14 ходовых часах в сутках это 2–3 календарных дня (решение 2026-09-26).
- ✅ Задание можно начать с 06:00 до **14:00 включительно**; с 15:00 группа выходит следующим утром (решение 2026-09-26). В коде — `DayRhythm.CanStartQuest` / `NextQuestStart`.

## Скорости и пауза

- Скорости: **пауза, ×1, ×2, ×4** (из `BalanceSettings`). ×1 = 1 такт в секунду реального времени.
- Отладочная скорость ×50 — только в отладочной сборке.
- `GameRunner` копит реальное время и вызывает `Tick()` нужное число раз; при подвисании кадра — не больше 10 тактов за кадр.
- **На паузе** игрок может смотреть экраны и отдавать команды — они применяются сразу (ТЗ 01).
- Горячие клавиши: **Пробел** — пауза / продолжить, **1 / 2 / 3** — скорости.

## Автопауза

- `AutopauseSystem` ставит паузу в конце такта, если в такте было событие из списка ниже и этот вид включён в настройках.
- Настройки автопаузы — переключатели по видам событий (экран «Время»). По умолчанию включены все.
- Во всплывающем окне автопаузы — строка ленты, которая её вызвала, и кнопка «Перейти» (к человеку, заданию или обращению).

| Событие | В прототипе |
|---|---|
| Гибель авантюриста | ✅ |
| Бегство авантюриста | ✅ |
| Катастрофа на задании | ✅ |
| Отступление группы | ✅ |
| Раскрытие скрытой черты | ✅ |
| Уход авантюриста или сотрудника из гильдии | ✅ |
| Начало банкротства | ✅ |
| ❔ Новое обращение (дилемма) | ✅ (в дизайне — открытый вопрос, по умолчанию включено) |
| Срочное событие, приход конкурента, предвестники, спецгруппа, пересмотр зарплаты | вне прототипа |

## Месяц

- В начале месяца (`MonthStarted`): выплаты и **отчёт месяца**. Отчёт появляется уведомлением, без автопаузы.

## Критерии приёмки

- [ ] Время идёт по часам, календарь правильно переходит через сутки, месяц, год.
- [ ] Фазы дня переключаются по часам из `BalanceSettings`.
- [ ] Пауза, ×1, ×2, ×4 работают, горячие клавиши работают.
- [ ] Ночью группы ночуют, а не идут.
- [ ] Автопауза срабатывает на каждом событии из списка и отключается в настройках.
- [ ] На паузе команды применяются сразу.

## Открытые вопросы

- ❔ Час старта игры, ночлег групп, запрет на выход после 14:00.
- ❔ Автопауза на новое обращение.

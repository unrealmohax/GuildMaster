# GM-14. Интерфейс наблюдения

| Задача | Ветка | Метки коммитов |
|---|---|---|
| **GM-14** | `GM-14_ui_observation` | `[GM-14]` — код, `[TechSpec-14]` — правки этого ТЗ |

Дизайн: [prototype.md → Экраны](../docs/prototype.md#экраны), [core-loop.md](../docs/core-loop.md). Технология: **uGUI + TextMeshPro** (GM-01).

## Цель

**Этап 2.** Экраны без графики — списки, карточки, ленты, — через которые игрок наблюдает за гильдией: люди, доска, задания в пути, время. Плюс отладочная панель. Экраны и навигация устроены так, что новые экраны и действия добавляются без переделки.

## Опирается на

- GM-01: `ISimulationClient`, команды, `UiRoot`. GM-03: скорость, пауза, автопауза, календарь.
- GM-04, GM-05: люди, состояние, лояльность словами, раны. GM-07: ленты, ссылки в строках. GM-08: причины важных решений.
- GM-09: казна, банкротство. GM-10: доска, репутация. GM-11: задания в пути, лента задания. GM-12: группы. GM-13: постройки, персонал.

## Общие требования

- Опорное разрешение **1920×1080**, Canvas Scaler — Scale With Screen Size.
- ✅ (2026-09-28) Тёмная тема (фон #15171C, панели #1E2128, текст #D8D4CC, серый #8A8A8A), один акцентный цвет — охра #D4A24C; красный #C8554B — только сигнал (минус в казне, банкротство, тяжёлая рана, гибель). Шрифт — LiberationSans из TMP Essential Resources, статический SDF с латиницей, кириллицей и значками. Иконки — простые символы (♦ ■ ◄ ►) или текст.
- Навигация — левая панель: **Гильдия, Доска, Задания**. Карточка авантюриста открывается поверх.
- Любое имя человека, заказа, задания в тексте — **кликабельно** (переход по `Links` строки).
- UI обновляется по событиям симуляции, не каждый кадр целиком.
- Строки лент по важности: [О] — серый текст, [З] — цветной, [В] — крупно, со значком.
- Всё, что меняет мир, — только команды (GM-01).

## Верхняя панель (всегда видна)

| Элемент | Что показывает / делает |
|---|---|
| Дата и время | «День 12, месяц 1, год 1 · 14:00» + фаза дня (утро / день / вечер / ночь) |
| Скорость | ⏸ ×1 ×2 ×4, текущая подсвечена (горячие клавиши — GM-03) |
| Казна | Сумма; красным при минусе |
| Репутация | Число 0–100 |
| Люди | «14 / 30» |
| Уведомления | Колокольчик со счётчиком; список уведомлений — расширяемый. Сейчас: важные заказы, событийные задания, кандидаты в авантюристы и персонал, отчёт месяца. Клик по уведомлению ведёт к объекту |
| Банкротство | Если идёт — таймер «до закрытия: 3 мес. 12 дн.» красным |

## Экраны

### 1. Гильдия

Вкладки + **лента гильдии** справа (всегда на этом экране).

- **Люди**: таблица — имя, архетип, ранг, занятие («на задании: охота у …», «тренируется», «в таверне», «лечится»), значки ран, полоски усталости и стресса, довольство, лояльность словами, кошелёк. Фильтры по занятию. Сортировка по столбцам. Клик — карточка.
- **Группы**: постоянные группы и их члены.
- **Постройки**: список с состоянием (готова / строится — сколько дней / в очереди), вместимостью («Общежитие 7/10»).
- **Персонал**: сотрудники (должность, уровень, зарплата, долг по зарплате).

### 2. Доска (просмотр)

- **Слева** — заказы на доске: тип, ранг, заказчик, близко/далеко, награда, доплата, сколько висеть, кто взял.
- **Справа** — выбранный заказ: описание с намёками.
- Профиль задания и шанс **не показываются никогда**.

### 3. Карточка авантюриста

| Блок | Содержимое |
|---|---|
| Шапка | Имя, пол, возраст, архетип, ранг гильдии + полоска очков, ранг характеристик |
| Профиль ролей | «Щит 68, Боец 49, Разведчик 30…» |
| Параметры | 8 характеристик и 6 навыков — точные числа |
| Характер | 6 осей: нераскрытая — «?», раскрытая — название полюса («Трус», «склонен к риску», «уравновешен») |
| Особые черты | Только раскрытые. ✅ (2026-09-28) Число скрытых не показывать |
| Состояние | Усталость, стресс, довольство — полоски с числом; лояльность — словами (GM-05) |
| Здоровье | Раны со сроком («Тяжёлая рана — 9 дн.»), Калека |
| Деньги | Кошелёк, долг гильдии, жильё (город / общежитие) |
| Отношения | Друзья, неприязнь, соперник, влюблённый (раскрытые) |
| Сейчас | Занятие; для важных решений — причина (GM-08) |
| История | Заданий выполнено / провалено; последние строки ленты о нём |

### 4. Задания (задание в пути)

- **Слева** — идущие задания: тип, место, группа, фаза («путь туда», «на месте, раунд 2», «назад»).
- **Справа** — выбранное: заказ, участники (значки ран, паника, «повернул назад», «сбежал», «погиб»), полоска фазы, **проваленные раунды — 5 делений**, **лента задания**.
- Недавно вернувшиеся (30 дней) — отдельным списком с итогом.

### 5. Время

- Управление скоростью — на верхней панели.
- **Календарь** (по клику на дату): текущая дата, до начала месяца N дней, ближайшие события — окончание стройки, сроки ответа на важные заказы, возвращение групп. Список видов событий календаря — расширяемый.
- **Настройки автопаузы** — переключатели по видам событий (GM-03).

## Отладочная панель

Только в отладочной сборке, клавиша **F1**. Список функций — расширяемый.

| Функция | Что делает |
|---|---|
| Зерно | Показать текущее, перезапустить с заданным |
| Скорость ×50 | Отладочная скорость (GM-03) |
| Перемотать | На N часов / дней вперёд |
| Раскрыть всё | Показывать скрытые черты, профиль и шанс заданий (для отладки) |
| Деньги | + / − N |
| Репутация | Задать |
| Человек | Создать с заданной ролью и чертами; изменить параметр, ось, показатель |
| Заказ | Создать с заданным типом и рангом |
| Событие | Вызвать засаду, находку, срыв |

## Критерии приёмки

- [x] Все экраны открываются из навигации, данные обновляются на ходу.
- [x] Ни один экран не показывает профиль задания, шанс или скрытые черты (кроме «Раскрыть всё» в отладке).
- [x] Клики по именам ведут к карточкам и заданиям.
- [x] Интерфейс читается на 1920×1080 и 1280×720.
- [x] Отладочная панель доступна только в отладочной сборке.

## Решения автора (GM-14)

✅ (2026-09-28, «все по рекомендациям») — подробно в `docs/decisions.md`: экраны собирает код (в сцене — Canvas и `UiRoot`), вложенные Canvas по слоям,
навигация — `UiNavigator` (экраны по id, стопка окон, Esc); обновление по `StateChanged` с ограничением частоты; числа интерфейса — `UiTheme`;
`UiRoot.Bind(клиент, часы, сессия)`; автопауза и уведомления — по состоянию мира; ссылки в строках — места подстановки меток в `FeedEntry.Spans`;
`QuestRun.PhaseHours`, текст причины ухода у человека; отладочные команды — в Core; граница с GM-15 — только наблюдение.

## Принятые при реализации допущения ❔ (GM-14)

- **Ссылки.** Ссылку получают: люди (на человека), `{имя}` сотрудника (на сотрудника), место, враг, заказчик, груз (на задание, а без него — на заказ),
  постройка (на постройку с этим определением), группа и её название (на группу, без `partyId` — на задание). Группа под задание ведёт к своему
  заданию, постоянная — во «Группы». Ушедший и погибший открываются в карточке с пометкой и причиной ухода.
- **Ленты.** Новые строки — сверху; на экране — не больше `feedLinesShown` (150) строк; [О] — серым, [З] — акцентом, [В] — крупнее, жирно, со значком ♦.
  Имена — светлым в обычной и заметной строке, акцентом — в важной.
- **Люди.** Лояльность сортируется по словам, при равном слове — по id (число не просачивается через порядок). Фильтр «Срыв» — идущий срыв или запой.
  Значки ран: ■ акцентом — лёгкая, ■ красным — тяжёлая, «К» — калека. Кандидаты в гильдию — строками под таблицей, имя кликабельно.
- **Постройки** — все из данных: построенные, стройка («строится — ещё N дн.»), очередь, «не построена»; места — только у готовой.
- **Персонал.** Сотрудники таблицей; кандидаты на вакансии — строками (должность, уровень, просимая зарплата, сколько ждёт).
- **Доска.** Слева — заказы на доске и в работе (в работе — серым, «Взял» — кто вышел); отметки важный / событийный / экзамен — значком ♦ и в карточке заказа.
  У экзамена срока на доске нет — «без срока».
- **Задания.** Полоска — доля пройденной фазы (путь или раунд); недавно вернувшиеся — пока хранится их лента (`questFeedKeepDays`), итог — только
  «выполнено / не выполнено».
- **Карточка.** Параметры — базовые значения с одним знаком после запятой; ранг характеристик — `PowerScore`; профиль ролей — по параметрам
  с постоянными модификаторами; раскрытая нейтральная ось — «уравновешен(а)»; друзья и неприязнь — по порогам, всегда; соперник и влюблённый —
  раскрытые черты с партнёром. Последние строки — до 8 строк ленты гильдии, где человек назван.
- **Календарь** — конец текущей стройки, сроки ответа на важные заказы и событийные задания, возвращение групп на обратном пути (время — с ночлегами).
  Клик — к объекту. Переключатели автопаузы — там же.
- **Уведомления** — по состоянию мира: важные заказы и событийные задания без ответа (→ Доска), кандидаты (→ карточка кандидата), кандидаты
  на вакансии (→ Персонал), непрочитанные отчёты месяца (→ окно отчёта, просмотр текстом). «Прочитано» помнит интерфейс, не мир.
- **Окно автопаузы** — строка ленты этого события (или первый вариант шаблона), «Перейти» — к первому участнику, заданию, заказу или сотруднику;
  «Продолжить» снимает паузу. Новое окно — на новую автопаузу.
- **Отладка.** «Отладочная сборка» — `Debug.isDebugBuild` (редактор, Development Build). Действия над человеком — с последним открытым в карточке,
  над заданием — с последним выбранным на экране «Задания». Засада и находка случаются в ближайший ходовой час обычным ходом задания; срыв — вид по
  чертам. Деньги отладки — статьи журнала «Отладка: пополнение / изъятие» (изъятие — обязательное, даже в минус). Новый человек — без кандидатства,
  черты с партнёром пропускаются. Новый заказ — сразу на доску, мимо Регистратора, не важный. Перемотка идёт такт за тактом, автопаузу пропускает
  (причины — в лог Unity), перезапуск начинает на паузе.
- **Частоты** — верхняя панель ≤ 10 раз/с, открытый экран и окна ≤ 4 раз/с (`UiTheme`); кадр на ×4 — ~2,1 мс, скрипты — ~0,04 мс в среднем.
- **Тексты.** Подписи интерфейса — `UiStrings`; занятие, срыв, фаза, раны, стадии построек — шаблоны `ui.*` (валидатор требует каждый ключ `UiTextKeys`).
